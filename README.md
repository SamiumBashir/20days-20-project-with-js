## 💻 Getting Started

These are small frontend projects built with HTML, CSS, and JavaScript.
For projects that don't require a build tool, you can run them directly
in your browser.

### 1. Clone the repository

``` bash
git clone https://github.com/SamiumBashir/20days-20-project-with-js.git
```

### 2. Open the project folder

``` bash
cd 20days-20-project-with-js
```

### 3. Run a project

Open the relevant project's folder and launch its `index.html` file in
your browser. You can also use the **Live Server** extension in Visual
Studio Code.

> If a future project requires an API key, a development server, or
> additional setup, follow the instructions provided in that project's
> folder.
